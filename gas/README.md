# Google に載せる手順（段階4）

このフォルダの2つのファイルを、Google の Apps Script に貼り付けて公開します。

| ファイル | 貼る場所 |
|---|---|
| `Code.gs` | Apps Script の「Code.gs」 |
| `Index.html` | Apps Script に新しく作る HTML ファイル「Index」 |

★この2つは `bash tools/build-gas.sh` で自動で作られたものです。直接は直さず、元のファイルを直してから作り直します。

---

## 最初の1回だけ（15〜20分）

### 1. スプレッドシートを作る
1. Google ドライブを開き、「新規」→「Google スプレッドシート」を押す
2. 左上の名前を「**タイピング練習の記録**」に変える
   （typing-log のスプレッドシートとは別のものです）

### 2. Apps Script を開く
1. スプレッドシートのメニューの「**拡張機能**」→「**Apps Script**」を押す
2. 左上の「無題のプロジェクト」を押して、名前を「**タイピング練習**」にする

### 3. Code.gs を貼る
1. 最初から入っている `function myFunction() { … }` を、**全部消す**
2. このフォルダの `Code.gs` をメモ帳で開き、Ctrl+A（全部選ぶ）→ Ctrl+C（コピー）
3. Apps Script の画面に Ctrl+V（貼り付け）→ Ctrl+S（保存）
4. **確かめ**：いちばん下までスクロールして、最後が `}` で終わっていること（途中で切れていないこと）

### 4. Index.html を作って貼る
1. 左の「ファイル」の横の「**＋**」→「**HTML**」を押す
2. 名前に `Index` と入れる（**I は大文字**。「.html」は自動でつきます）
3. 最初から入っている中身を全部消す
4. このフォルダの `Index.html` をメモ帳で開き、Ctrl+A → Ctrl+C → Apps Script に Ctrl+V → Ctrl+S
5. **確かめ**：いちばん下が `</html>` で終わっていること

### 5. シートを作る（setup を1回実行）
1. 上の「実行」ボタンの横にある関数の選択で「**setup**」を選ぶ
2. 「**実行**」を押す
3. 「承認が必要です」と出たら、「権限を確認」→ 自分のアカウントを選ぶ
4. 「**このアプリは Google で確認されていません**」と出たら、「詳細」→「タイピング練習（安全ではないページ）に移動」→「許可」
   - これは、自分で作ったプログラムを初めて動かすときに必ず出る画面です。
5. 下の「実行ログ」に「シートの準備ができました」と出れば成功。スプレッドシートに「利用者」「文章」「記録」の3つのシートができています

### 6. 登録用の合言葉を決める
1. 左の **歯車（プロジェクトの設定）** を押す
2. いちばん下の「**スクリプト プロパティ**」→「スクリプト プロパティを追加」
3. プロパティに `REGISTER_CODE`、値に **登録用の合言葉**（新しく登録する人だけに教える合言葉）を入れて「スクリプト プロパティを保存」
   - **半角の英数字**にしてください。登録画面の欄は日本語入力が働かないので、日本語の合言葉は入力できません

### 7. ウェブアプリとして公開する
1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 「種類の選択」の歯車 →「**ウェブアプリ**」
3. 説明：「最初の版」
4. 次のユーザーとして実行：「**自分**」
5. アクセスできるユーザー：「**全員**」
6. 「デプロイ」を押し、出てきた「**ウェブアプリの URL**」をコピーしてメモする

### 8. 開いて確かめる
1. メモした URL を開く（シークレットウィンドウでも大丈夫です）
2. ログイン画面のいちばん下に「画面の版：○○　／　Google 側の版：○○」と出て、**2つが同じ**なら成功
3. 「はじめての方は、こちらから新しく登録」から、自分の利用者名と合言葉を登録する
   - 合言葉は、半角の英字・数字・記号で8文字以上です（共用PCの予測変換に残らないよう、日本語は使えません）

★アプリは必ず **ウェブアプリの URL** から開きます。`index.html` を直接開くと、Google につながらない開発用の画面になり、登録した利用者名ではログインできません。

## 直したものを Google に反映するとき（2回目から）

1. 手元で `bash tools/build-gas.sh` を実行して、2つのファイルを作り直す（Claude が行います）
2. 上の 3 と 4 と同じように、Code.gs と Index の中身を**全部消してから**貼り直し、保存する
3. 「デプロイ」→「**デプロイを管理**」→ 鉛筆（編集）→ バージョン：「**新バージョン**」→「デプロイ」
   - この方法なら **URL は変わりません**（利用者さんに新しい URL を知らせなくて済む）
4. URL を開き直して、ログイン画面の版の番号が新しくなっていることを確かめる

## スプレッドシートの見かた（管理者向け）

3つのシートがあります。1行が1件です。**中身を直接書きかえないでください**（アプリが読めなくなることがあります）。

- setup を実行すると、3つのシートに「**警告を表示**」の保護がかかります。セルを書きかえようとすると確認が出るので、「キャンセル」を押してください。
  この保護は人の操作にだけ働き、アプリの保存や削除はそのままできます。
- もし書きかえてしまったときは、スプレッドシートの「ファイル」→「変更履歴」→「変更履歴を表示」から、前の状態に戻せます。

| シート | 1行の中身 | 管理者に読めるもの |
|---|---|---|
| 利用者 | 登録した人1人分 | 利用者名、登録した日時。合言葉の欄は「確認用の印」なので、合言葉そのものは分からない |
| 文章 | 保存した文章1つ分 | 番号、利用者名、保存した日時。**タイトルと本文は鍵つきで読めない** |
| 記録 | 練習1回分 | 利用者名、練習した日時、速さ・正確率・ミスなどの数字。文章のタイトルは鍵つきで読めない |

記録のシートの中の、英語のままの値の意味です。
- 段階：ふつう／長文／やさしめ／本番、saved（保存した文章）、custom（保存していない貼り付け文章）
- 完了したか：true（最後まで打った）／false（途中終了）
- 判定：strict（きびしい）／lenient（ゆるい）
- 配置：sample-left（左に見本）／input-left（左に入力）／sample-top（上に見本）／input-top（上に入力）
- 日時は日本時間で「2026-10-17T13:58:12.551+09:00」の形（＝2026年10月17日 13時58分12秒）

## 知っておくこと

- ページのいちばん上に「Google Apps Script のユーザーによって作成されました」という帯が出ますが、消せません。使うのには困りません
- 保存や読み込みに、1回あたり1〜2秒かかります
- ログインは6時間で自動的に切れます（Google の決まり）。切れたらログインし直します
- 文章のタイトルと本文は、鍵がかかった形でスプレッドシートに入ります。スプレッドシートを開いても読めません
- スプレッドシートは**だれとも共有しない**でください。利用者さんはアプリの画面だけを使います
- 他の利用者さんに広げる前に、支援員さんに相談する約束です
